# Методическая база агента

## Когда применять
- Открывай индекс, когда нужен метод для текущего шага работы.
- Это методики, а не сведения о конкретном рынке или продукте.
- Индекс помогает выбрать один нужный файл, а не загрузить всю базу.

## Принципы
- Читай только файл, который нужен на текущем шаге; остальные не загружай.
- При переходе к другой задаче выбирай следующий файл по индексу.
- Не читай связанные файлы автоматически: сначала назови конкретную потребность.
- Методика не заменяет вводные человека, источники и выбор варианта.
- Примеры в базе учебные; их нельзя переносить в проект как факты.
- Правила AGENTS.md и рабочих навыков сохраняют силу.

## Индекс: когда читать
- `README.md` — когда нужно выбрать методику и ограничить загрузку контекста.
- `evidence-and-statuses.md` — когда собираешь источники или проверяешь статусы утверждений.
- `research-methods.md` — когда строишь план исследования, сопоставляешь данные или решаешь остановиться.
- `options-and-objections.md` — когда формируешь разные варианты и проверяешь сильные возражения.
- `product-strategy.md` — когда раскрываешь выбранный вариант в продуктовую стратегию.
- `communication-strategy.md` — когда связываешь аудиторию, барьер, сообщение и каналы.
- `validation-plan.md` — когда задаёшь способ проверки результата и правила решения.
- `checklists.md` — когда готовишь показ вариантов, стратегии или закрытие решения.

## Пошаговая процедура
1. Прочитай состояние проекта и определи текущую задачу.
2. Сформулируй, что именно мешает её выполнить.
3. Выбери по индексу файл, который отвечает на этот вопрос.
4. Прочитай его, не загружая соседние методики на всякий случай.
5. Примени подход к материалам проекта, сохраняя их ограничения.
6. Запиши результат в предусмотренный рабочим навыком файл.
7. Если возникла другая задача, заново выбери нужную методику.

## Типичные ошибки
- Загружать всю базу перед каждым шагом.
- Подменять доказательство ссылкой на методический файл.
- Выдавать учебный пример за наблюдение о пользователях.
- Расширять исследование только потому, что в базе есть ещё методы.
- Менять согласованный вариант без нового выбора человека.

## Мини-пример
- Ситуация: варианты подготовлены, но отличаются только бюджетом.
- Открой `options-and-objections.md`, чтобы проверить оси различий.
- Не загружай коммуникационную стратегию до выбора варианта.
- Перед показом отдельно открой нужный чек-лист из `checklists.md`.
- Пример учебный; он не описывает состояние какого-либо проекта.
