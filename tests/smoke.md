# Одиннадцать smoke-сценариев агента

## Общая подготовка
- Сценарии запускаются только по отдельному разрешению, в новых сессиях и изолированных папках по tests/README.md.
- Все вводные ниже учебные: они не являются наблюдениями о реальном рынке.
- Если нужны шаблоны, копируй их из projects/_template/ без переименования колонок CSV.
- Во всех подготовленных state.md: project_id равен имени папки; версия инструкций — полученный хеш или н/д; дата обновления — фактическая дата подготовки.
- Если сценарий не задаёт решение, вопросы, допущения или блокеры, запиши в соответствующем поле `нет`; не оставляй подсказки-заготовки.
- У созданного проверяющим источника дата обращения — фактическая дата чтения файла при подготовке; тип — `учебный материал`, надёжность — `только для проверки поведения; не рыночное свидетельство`.
- Поля «Результат» ниже намеренно пустые: их заполняют только после реального прогона.
- Единственный журнал событий и затрат проекта — events.csv; поля и примеры — projects/_template/FIELDS.md. Архивный cost-log.md не дополняется и не суммируется с ним. Transcript и этот журнал результатов тестов — свидетельства проверки, не дополнительные журналы затрат.
