# Учёт измерений

## Вопрос

ВВОДНЫЕ ОТ ЧЕЛОВЕКА (22.11.2026): реализовать остающийся исполняемый учёт реального времени, токенов и стоимости. Сначала предложить способ и дождаться согласия; после предложения получена команда «начинай».

## Цель

Для будущих исполнений сохранять измеренные интервалы и привязанные отчёты о расходе в совместимом events.csv, без восстановления прошлых значений.

## Получатель

Агент, ведущий проекты в этом репозитории, и человек, читающий журнал и сводку.

## Ограничения

CLI `opencode` в текущей среде не найден. Стоимость требует заполненного человеком docs/PRICING.md. Исторические журналы не переписываются; секреты и полные запросы не сохраняются.

## Данные

Формат журнала — projects/_template/events.csv и FIELDS.md. Контрольная точка — state.md. Существующая сводка — tools/cost_summary.py. Отчёт конкретного вызова передаётся отдельным файлом только при наличии точных данных.

## Допущения

Выполняющий агент вызывает start/pause/resume/finish на границах работы. Отчёт вызова создаёт интеграция с модельным исполнителем; этот репозиторий не управляет исполнителем ChatGPT.

## Пробелы

В текущем окружении нет доступа к отчёту о токенах этого разговора. Применимый тариф не задан. Эти значения остаются «н/д».

## Источники

- Без id — вводные человека, текущий диалог, 22.11.2026.
- Без id — projects/_template/FIELDS.md, прочитано 22.11.2026.
- Без id — docs/PRICING.md, прочитано 22.11.2026.
