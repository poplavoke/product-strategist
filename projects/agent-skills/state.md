## Открытые вопросы

### Блокирующие
- Нет для завершённого объёма правки инструкций.

### Неблокирующие
- Автозагрузка навыков, автоматические поведенческие проверки и запуск GitHub workflow не подтверждены этой сверкой. Наличие файлов не доказывает исполнение.
- Git недоступен; хэш, текущая ветка и серверное состояние не подтверждены. Прежние записи об интеграции сохранены как история в decisions.md, не считаются новой проверкой.
- CLI opencode недоступна в этой оболочке: --version и stats --help не выполнены из-за отсутствия команды; токены и стоимость н/д. Новые проверки скрипта не запускались. Затраты измеряемой части и оговорки — metrics-summary.md.

## Допущения
- Это система файловых инструкций. CSV-журналы и описание полей существуют; исполняемый оркестратор, контрольные точки и автоматическая валидация состояния не реализованы этим изменением.
- metrics задаёт измерения, выполняемые агентом на границах шагов; это не автономный сборщик. Его текущая контрольная точка предназначена для возобновления, а не для принудительного оркестратора.
